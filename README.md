# Bumm Bumm Rakete 🚀

Rhythmus-Feuerwerk im Browser: Zünde die Raketen im Takt und mach den Himmel bunt. Inoffizielles, nicht-kommerzielles Fan-Projekt, inspiriert von „Boom Boom Rocket“ (Xbox 360, 2007).

**Spielen:** https://edwon3k.github.io/bumm-bumm-rakete/

- Steuerung: Tastatur (Pfeile / WASD, Leertaste), Controller oder Touch
- Online mit Freunden: Raum erstellen, Code teilen, gleichzeitig spielen. Keine Anmeldung nötig, die Verbindung läuft direkt zwischen den Browsern.
- Eigene Lieder: werden nur im eigenen Browser gespeichert und im Raum direkt an die Mitspieler geschickt.
